Inter-Rater Agreement — Guide
Example
3 clinical psychologists rate 80 patient videos on 2 dimensions: depression severity (ordinal, 4 categories) and risk classification (ordinal, 0–4). Each rater uploads their own CSV file (80 rows × 2 columns). Then, for each dimension individually and globally, the tool computes how well the three raters agree — and what share of the agreement goes beyond chance.
CSV Format
A separate CSV file is expected for each rater.
Rows = stimuli (targets, people, items) — one row per rated object.
Columns = dimensions (scales, attributes) — one column per rating dimension.

Numbers only; optionally a first row of column headers (D1, D2 …).
Delimiter: comma , or semicolon ; (detected automatically).
Example: 3 raters score 80 patients on 4 scales → each file has 80 rows × 4 columns.
D=1 (standard case): Just one dimension — then each file has n rows × 1 column (a single numeric column).

Methods
MeasureWhen
Cohen's κExactly 2 raters, nominal or ordinal (unweighted)
Cohen's κ (weighted)2 raters, ordinal — linear weight penalizes larger deviations more
Fleiss' κ3 or more raters, nominal or ordinal
Krippendorff's αAny number of raters, all scale levels; tolerates missing values
Gwet's AC1Nominal, any number of raters; more robust than κ with unequal category frequencies (no kappa paradox)
Gwet's AC2Ordinal, linear/quadratic weighted; chance correction based on equal category distribution, not marginals
ICC(1,x)Each stimulus rated by different, randomly chosen raters
ICC(2,x)Same raters, treated as a random sample — agreement (conservative)
ICC(3,x)Same fixed raters — consistency (bias is partialled out)
Gwet AC1 / AC2 — Formula
AC = (pa − pe) / (1 − pe)
pa = observed (weighted) agreement.
pe = (1/K) · Σk πk · (1 − Σl wkl · πl) — Gwet chance correction (equally weighted categories).
K = number of categories; πk = mean probability for category k; wkl = weight matrix.

SE and p-value via t-test (df = n − 1) based on the per-stimulus AC estimators gs = (pa,s − pe) / (1 − pe).
Implementation analogous to irrCAC::gwet.ac1.raw().

Kendall's W
Concordance measure for ordinal data with ≥ 2 raters. W = 0: no agreement, W = 1: perfect concordance. Always computed additionally to the main measure when scale level = ordinal.
Bland-Altman Plot
Interval scale only. Shows the mean of both raters (x-axis) against their difference (y-axis). Bias = mean difference. LoA (limits of agreement) = bias ± 1.96 × SD(difference). Selectable per dimension when D > 1.

▶ Kendall's W — Rank Concordance
Kendall's W
Measures the concordance of all raters simultaneously based on ranks. W = 0: no agreement; W = 1: all raters rank identically.
Computed per dimension; χ² test checks whether W > 0 (df = n_stimuli − 1).
▶ ICC — Intraclass Correlation
ICC(x,1) and ICC(x,k)
ICC(x,1): reliability of a single measurement (1 rater per person).
ICC(x,k): reliability of the mean of all k raters (Spearman-Brown corrected).

Reference values (Koo & Mae 2016):
< .50 poor · .50–.74 moderate · .75–.89 good · ≥ .90 excellent
▶ Heatmap — Dimension × Rater
Heatmap
Shows the pairwise agreement value (chosen method) for each rater pair (row) and each dimension (column).
Red = low agreement; green = high agreement.
Red cells show on which dimensions two raters agree especially poorly; green cells signal good pairwise agreement.
▶ Bland-Altman Plot
Bland-Altman
Shows for each rater pair: x-axis = mean of both values, y-axis = difference.
Bias = mean difference. LoA = bias ± 1.96 SD.
Points outside the LoA = systematic discrepancy between the rater pair.
